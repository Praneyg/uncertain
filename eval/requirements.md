# Requirements derived from the spec

Source of truth: `π-infoval-library (1).pdf` ("Library Design Proposal", 11 sections + Appendix A).
Section references (§) are to that PDF. Library under test: `src/uncertain` (working tree, including
uncommitted changes, at the time of evaluation).

Inputs as resolved for this run (the prompt left them as placeholders):
`repo_root=./`, `package_name=uncertain`, `small_real_model=openai-community/gpt2` at the revision
pinned by the repo (`607a30d7…`, local HF cache, offline), `compute_budget=CPU only, full eval suite < 15 min`.

Grading methods: **code** = deterministic assertion; **stat** = Monte Carlo estimate against an
analytic value from `eval/toy_lm.py` using the library's own reported SE (pass if |est − truth| ≤ 4·SE);
**spy** = call counting / monkeypatched instrumentation; **LLM** = rubric-graded by a model
(criterion 25 only).

## Conflicts between the prompt's checklist and the PDF

| Prompt item | What the PDF says | Resolution |
|---|---|---|
| 8 — distances support arities (unit,unit), (set,unit), (set,set) | §4.5: "Distances are pointwise by construction… There is one signature, (unit, unit) -> float, no arity flag, and no branching." §4.1/§4.3: the observed unit is a set of size one (`anchor`). | Rewritten as B8: one pointwise signature; (set,unit) and (set,set) are *statistics* over sets, and the singleton case must agree with the pointwise distance. |
| 18 — "uses transpose(...).contiguous()" | §4.3/§10: "Axis reordering is done by named rearrangement, never by reshape… checked at construction by a shape assertion and an alignment assertion". §9 oracle 2 is the test that catches it. | Tested as: no reshape-based axis reordering + every log-prob path agrees with an independent teacher-forced pass, and per-row values survive the only batched logits path (`StudySampler`). |
| 17 — "spy on generate()" | §4.4: top_k defaults to 0. The library never calls HF `generate()`; it samples with an explicit numpy filter (`sampling_probabilities`). | Spy on `sampling_probabilities` instead. |
| 23 — batched == unbatched | Not stated in the PDF. Nearest text: §6.3 "results bit-reproducible from a seed"; §3 "utils/ … batching helpers". | Kept, marked **AMBIGUOUS**; sub-checks are reported. |
| 5 — mean pairwise "documented as non-zero when P = Q" | §4.6 and §9 state this property; "Mean pairwise distance remains available". | Kept; tested numerically. |
| Out-of-scope list in the prompt names `metrics/`, `viz/`, `adapters/` | The PDF's §11 list: analysis/plotting, importance sampling/variance reduction, adaptive set sizing, further statistics/distances, parsing units, beyond-text, optimal stimulus design. Mixing units/levels in one run is "explicitly unsupported" (§4.2). | Both lists respected; neither is penalised. |
