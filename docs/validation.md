# Validation and release gates

The tests exercise a finite suffix-conditioned model with analytically known
probabilities, plus a locally initialized two-layer GPT-2. No pretrained model
or external corpus is needed. Assertions use independent formulas or model
teacher-forced outputs, rather than golden values generated by the implementation.

## Checks

- Raw sampled token log probabilities match an independent teacher-forced forward.
  A deliberate transpose/reshape corruption fails that comparison.
- Temperature/top-k q-probabilities match an independent logits calculation.
- Exact token probability, log probability, span probability, and next-token
  entropy match small known distributions; MC convergence is checked over seeds.
- Rare/zero events preserve meaningful probability intervals and infinite
  surprisal endpoints. Long exact surprisals avoid product underflow.
- Energy agrees with direct dense formulas; permutations and block sizes leave
  values unchanged. Its cosine mean-only limitation is tested explicitly.
- Truncation, extension, EOS/budget behavior, word lookahead, Unicode boundaries,
  and retokenization errors are covered. Sample buffers cannot be made writable.
- Compatible sweeps generate once per unique state at the maximum needed horizon.
  Cold, in-memory, and fresh-process-style store replay produce matching rows;
  warm replay generates no samples. Checksums and request pointers are verified.
- Paired contrasts preserve shared-sample covariance. Extension components are
  loaded from files outside core. CSV/JSON/Parquet preserve the output contract.

Run the suite with `python -m pytest -q`. Install the `hf` extra for the four local
model tests and `tables` for Parquet testing. Optional dependency tests are skipped
when their dependencies are absent; inspect the summary rather than treating a
skip as a successful backend validation.

On this Windows sandbox, Python owner-only temporary directory permissions can
prevent pytest workers from accessing fixtures. `tests/conftest.py` supplies unique
non-sensitive fixture directories using normal inherited permissions. Set
`UNCERTAIN_TEST_TMP` to control their location. Production artifact files still use
atomic temporary-file writes.

## Remaining scientific/full-v1 gates

The implementation is a research alpha. The following are deliberately visible:

- GPT-2 exact scores now match the local study notebook across all 1,487 observations.
  Study-specific cosine formulas have same-sample original-helper checks and a
  completed sampling pilot. Full-dataset sampling, the second model and downstream
  analyses remain separate milestones. See `replication/README.md`.
- The study's off-diagonal estimators are explicit APIs, separate from generic
  energy and nested anticipation. Historical padding scores and dependent-row
  bootstrap intervals are not reproduced; see `docs/replication-plan.md`.
- Exact word/sentence event likelihoods and statistically defensible
  directed-minimum/entailment uncertainty remain unsupported, with explicit errors
  or unavailable statuses.
- POS/spaCy and arbitrary external NLI/parser models require the user's pinned
  resources. The callback interfaces can be exercised without those downloads.
- Large-model GPU batching, full dependency/OS matrices, and absolute performance
  targets are not validated by the tiny-model tests. The reference loop prioritizes
  auditable correctness and stable sample identity.
- Dataset distribution, public sample bundles, package-index naming, and a license
  for publication remain separate release decisions. No upload or publication is
  performed by building or testing this source tree.

The engine is useful before these gates close. It must not be labeled a complete
published-results reproduction or an unrestricted implementation of every
generalized-surprisal configuration.
